# TaskFlow

Gerenciador pessoal de tarefas simples, usado como projeto piloto de homologação do MadeCoders.

## Stack

- **Frontend:** Vite + React + TypeScript
- **Backend:** NestJS + TypeScript + Prisma
- **Banco de dados:** PostgreSQL
- **Infra local:** Docker Compose

## Estrutura

Este repositório será organizado em dois projetos independentes:

- `frontend/` — aplicação React
- `backend/` — API NestJS

Instruções de instalação e documentação da API serão adicionadas conforme o projeto avança (ver planejamento no MadeCoders).
